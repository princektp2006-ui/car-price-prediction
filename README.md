# Car Price Prediction using Machine Learning

## Overview
This project predicts used car selling prices using Machine Learning regression models.

## Models Used
- Multiple Linear Regression
- Lasso Regression

## Features
- Data preprocessing
- One-hot encoding
- Feature engineering
- Residual analysis
- Feature importance visualization

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Dataset Features
- Car_Name
- Year
- Present_Price
- Kms_Driven
- Fuel_Type
- Seller_Type
- Transmission
- Owner

## Results

| Model | RMSE | R² Score |

| Linear Regression | 1.6585 | 0.8502 |
| Lasso Regression | 1.7013 | 0.8424 |
